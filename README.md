# RIDAN IP website

Static GitHub Pages site for RIDAN IP Limited. Upload the contents of this directory to the repository root.

## Deployment

- Custom domain: `www.ridanip.com`
- HTTPS should be enabled in GitHub Pages.
- `CNAME` contains `www.ridanip.com`.
- `robots.txt` points to the canonical `www` sitemap.
- `sitemap.xml` lists all public HTML pages.

## Brand colours

- Navy: `#04112D`
- Copper: `#B8976C`
- White: `#FFFFFF`

## Process assets

- `assets/eggtimer-start.png` - filing/start of formal application process
- `assets/eggtimer-end.png` - grant or registration/end milestone

The website uses the process marks on the homepage lifecycle section.
